O GitHub Pages hospeda sites estáticos (HTML, CSS e 
JavaScript

Preparação do projeto
• O arquivo da página inicial precisa se chamar index.html e ficar na raiz da pasta (não dentro de outra pasta).
• Use apenas caminhos relativos: 
src
="
img
/
logo.webp
" e 
href
="estilo.css". Nunca C:\Users\... nem /home/....
• O GitHub diferencia maiúsculas de minúsculas: Foto.JPG e foto.jpg são arquivos diferentes. Padronize tudo em minúsculas, sem acentos e sem espaços nos nomes.
